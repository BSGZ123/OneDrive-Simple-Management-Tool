msbuild "OneDrive Simple Management Tool.csproj" /p:Configuration=Debug /p:Platform=x64 /p:CustomAfterMicrosoftCommonTargets="$PWD\Tests\HomeUi\Probe.targets" /p:OutputPath=bin\HomeUi\ /p:IntermediateOutputPath=obj\HomeUi\

## 第二轮人工验收

2026-10-04：用户确认本轮首页概览验收通过，并授权提交、推送主分支。各专项场景未逐项记录，以下步骤保留供后续回归使用：

1. 打开首页，核对每个真实账户的容量；点击“打开云盘”，确认进入对应账户。首页加载过程不应弹出交互登录窗口。
2. 启动上传或下载，返回首页；改变任务状态或移除任务后，核对进行中、等待/暂停、失败、完成、取消计数。此处仅统计本次会话中尚未移除的任务。
3. 让现有同步绑定开始同步或暂停，核对总数、活动数、暂停数和需关注数；需关注可能与其他状态重叠，每个有问题的绑定只计一次。
4. 点击四个快捷入口，核对页面和侧栏；反复进出首页，确认数据更新且无重复页面导航。
5. 断网后刷新，检查单个容量错误和超时提示；恢复网络后刷新应恢复。登录失效时，从该盘文件页重新登录，再回首页刷新。
6. 在浅色、深色及窄窗口下检查文字、进度条和滚动。新用户空状态、配置损坏等场景可通过隔离测试复现，无需修改正式配置。

容量在进入首页和手动刷新时读取，每个请求等待最多 30 秒；本地任务和同步统计由现有模型的状态通知更新。未知配额保持未知，不推算为零或跨账户合计。真实 Graph 响应、网络断连和交互重新登录未由隔离界面测试验证。
