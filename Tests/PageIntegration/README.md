# 第四轮：三页联合验收

本轮补齐首页书签入口和最近三项收藏，复用书签定位、错误处理与取消逻辑；首页刷新同时更新容量和本地收藏。书签页的标题、筛选、恢复入口与列表一起滚动，保留列表虚拟化；窄窗口自动使用紧凑侧栏，菜单按钮不覆盖页标题。长名称可换行，首页最多显示两行并提供完整名称提示。

三页的操作按钮共用按实际内容尺寸换行的容器，修复原容器以首个按钮确定单元格宽度、使较长英文文案被截短的问题。界面回归额外测量按钮文字所需宽度，与最终显示宽度比较。

键盘入口：首页和书签页按 F5 刷新，书签页按 Ctrl+F 聚焦筛选；书签列表按 Enter 打开所选项，搜索框和按钮保留各自的 Enter 行为。设置页的主题继续应用到首页、书签页及书签恢复确认弹窗。

## 可复现的本地验证

联合界面入口复用书签 WinUI 程序，新增流程在 `Tests/BookmarkUi/PageIntegrationChecks.cs`。使用真实生产页面、菜单、存储、定位服务和主题设置；配置位于独立输出目录，所有账户、文件和 Graph 响应均为虚构，网络处理器拒绝非 GET 请求。

```powershell
msbuild "OneDrive Simple Management Tool.csproj" /p:Configuration=Debug /p:Platform=x64 /p:CustomAfterMicrosoftCommonTargets="$PWD\Tests\BookmarkUi\Probe.targets" /p:OutputPath=bin\BookmarkUi\ /p:IntermediateOutputPath=obj\BookmarkUi\
& ".\bin\BookmarkUi\OneDrive Simple Management Tool.exe"
& ".\bin\BookmarkUi\OneDrive Simple Management Tool.exe" --english
```

运行结束自动关闭，结果为 `bin/BookmarkUi/probe-results/<语言>/result.txt`。截图由 XAML RenderTargetBitmap 生成，不包含系统标题栏和原生背景材质。项目使用本机已有依赖缓存完成还原，不升级依赖。

## 人工验收清单

2026-10-05：用户同意提交本轮实现并推送远端。真实账户、进程重启和完整物理键盘场景未逐项确认；以下步骤保留供专项回归，使用可丢弃的测试文件并记录结果。

1. 在设置页切换浅色、深色和跟随系统，依次访问首页和书签页；退出、重启后核对选择。材质不可用时应显示普通背景。
2. 从首页前往文件，收藏一个文件和一个文件夹；返回首页应出现最近收藏。点击文件应定位并选中，点击文件夹应打开内容。
3. 在同一云盘内改名或移动测试文件，再从首页和书签页打开；使用第二个账户验证同名文件不会串号。
4. 从书签页移除收藏，再返回首页或刷新；列表同步更新，云端文件保留。
5. 缩窄、缩短窗口，检查首页、设置、书签及错误提示可滚动查看。用长名称检查换行和完整名称提示。
6. 使用 Tab、Shift+Tab、Enter 操作，按 Ctrl+F 筛选、F5 刷新；搜索框按 Enter 不应打开之前选中的书签。加载时切页不应被迟到请求送回。
7. 断网或登录失效时检查错误提示，再恢复网络或到文件页重新登录后重试。配置恢复只用隔离测试，不破坏正式配置。
