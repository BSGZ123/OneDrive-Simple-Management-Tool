# 下载可靠性回归

运行：

```powershell
dotnet run --project Tests/DownloadRegression/DownloadRegression.csproj
```

测试直接编译生产 `DownloadSession`、HTTP 响应校验、下载 ViewModel 和任务管理器，使用实际 Downloader 5.9.6 与本机 TCP HTTP 服务。仅 Graph 元数据提供者、Windows Storage 和 UI 调度边界使用替身，不读取账户或令牌。

单文件与任务生命周期检查覆盖：

- 普通、空、单字节、没有 Content-Length 的文件；完成后的字节内容与 SHA-256 校验。
- 暂停等待旧请求退出，继续使用刷新后的 URL 和 Range；重复启动只有一个活动任务。
- 截断响应后保留进度；手动重试与自动重试；自动重试最多三次尝试。
- 链接失效后刷新；远程版本变化时从头开始；传输期间版本变化不能发布结果。
- 不支持 Range、忽略 Range、错误 Content-Range、416 响应的安全重下。
- 准备、下载和重试等待期间取消；保留原目标文件和其他任务文件。
- 相同目标路径互斥；保存被文件占用阻止时保持失败，解除占用后直接重试保存。
- 哈希错误不能完成；完成瞬间的取消不会删除已经发布的文件。
- UI 延迟回调不能覆盖终态，失败任务可以批量重试，中英文状态和错误资源齐全。
- 响应正文无数据时超时，有限重试后失败，恢复服务后可手动重试。

## 实现边界

- 暂停使用“取消并等待本次传输结束 + 保留 DownloadPackage”。恢复和每次应用层重试都重新获取 Graph 下载地址与文件版本。
- 单连接下载；应用层最多三次尝试，间隔 1、2 秒；库内重试关闭，避免叠加无限重试。正文读取超时 15 秒，HTTP 请求超时 30 秒。
- 任务在目标目录使用唯一的 `.cloudflow-<id>.tmp.download` 临时文件；库收尾后得到 `.tmp`，应用校验大小、可用 SHA-256/SHA-1 和远程版本后才替换目标文件。只有替换成功才显示完成。
- 取消只删除本任务拥有的临时文件。保存选择器创建的空目标占位文件会保留，避免误删用户文件。
- 续传状态仅在进程内保存，不开启库的自动恢复元数据。本轮不恢复重启后的任务；强制结束程序可能留下上述临时文件，不能据此自动恢复。
- 不升级 Microsoft.Graph，不改变上传行为。真实账户验收结论及 OneDrive CDN、断网等专项覆盖边界见下文与界面验证记录。

## 批量与文件夹下载

列表、网格的多选下载和文件夹下载选择一次保存目录，然后在任务页显示一个批次。扫描会遍历所有分页，保留子目录和空文件夹；搜索结果同时包含祖先和后代时只下载一次。扫描阶段显示已发现数量，传输阶段显示总字节、速度、文件完成数量和失败路径。

- 所有批次合计最多三个文件并发，每个文件复用原有单文件下载、校验和重试机制。
- 本地已有同名文件或目录自动添加 ` (2)` 等后缀；保留原文件，不合并已有目录。Windows 非法字符被替换，设备保留名加前缀，过长名称缩短；大小写或清理后的同名项仍保持独立。
- 暂停等待当前写入停止并保留进程内续传数据。失败重试仅处理未完成文件、未解析项目和未完成的目录分页，保留成功文件。
- 取消停止扫描和排队、等待活动传输结束并清理本批次临时文件；已完成文件及已创建目录保留，卡片显示“已取消”。
- 不支持下载共享快捷方式、跨盘项目和重解析点目标目录。遇到这些项目时报告失败，不把未扫描完整的目录标为完成。批次不跨应用重启恢复。

`BatchDownloadChecks.cs` 新增 17 组检查，包含嵌套/空目录、重叠选择、分页与文件失败重试、路径冲突、并发上限、扫描/传输暂停与取消，以及退出清理。`FileManagementRegression/DownloadTreeChecks.cs` 另有四组检查验证真实 Graph SDK 解析、分页范围及元数据校验。
