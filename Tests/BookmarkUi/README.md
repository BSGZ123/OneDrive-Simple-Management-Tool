# 书签 WinUI 验证

入口使用生产书签页、文件页、列表/网格菜单、书签存储和解析器。账户与文件均为虚构，Graph 请求由内存处理器响应；处理器拒绝非 GET 请求。配置和截图位于独立的 `bin/BookmarkUi/probe-results/<语言>/` 下，不读取正式用户配置或令牌，不访问真实 OneDrive。

```powershell
msbuild "OneDrive Simple Management Tool.csproj" /p:Configuration=Debug /p:Platform=x64 /p:CustomAfterMicrosoftCommonTargets="$PWD\Tests\BookmarkUi\Probe.targets" /p:OutputPath=bin\BookmarkUi\ /p:IntermediateOutputPath=obj\BookmarkUi\
& ".\bin\BookmarkUi\OneDrive Simple Management Tool.exe"
& ".\bin\BookmarkUi\OneDrive Simple Management Tool.exe" --english
```

运行完毕自动关闭，结果写入 `result.txt`。需要交互式 Windows 用户会话。截图由 XAML RenderTargetBitmap 生成，不包含系统标题栏按钮和原生合成背景。
