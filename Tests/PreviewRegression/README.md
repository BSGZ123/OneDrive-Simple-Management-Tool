# 预览可靠性回归

运行：

```powershell
dotnet run --project Tests/PreviewRegression/PreviewRegression.csproj
```

直接编译生产 PreviewSession、PreviewContentLoader、GraphPreviewSource、PreviewPdfProbe、PreviewViewModel 和错误分类；Graph 使用真实 SDK 与内存 HTTP 响应。平台及本地化边界使用现有测试替身，不读取账户、令牌或真实文件。

覆盖 23 组检查：

- UTF-8、带 BOM 的 UTF-16、空 Markdown、无效编码。
- UTF-8/16/32 BOM、大小端、严格解码、截断序列、非法码点；无 BOM 手动选择 UTF，GB18030/GBK/Big5，空 TXT 和 TXT 大小边界。
- 编码失败后同会话重新解码、正文与元数据请求次数保持一次、再次选择错误编码与恢复、关闭清除缓存。
- 字号边界、复杂 Markdown 降级条件、100% 原始比例与 DPI 适应计算、位图和 SVG 解码预算。
- 元数据超限时不请求正文；实际字节限制覆盖未知或不实大小、边界大小。
- 截断、空图片、空流、无效下载地址。
- 请求和正文停滞超时；取消传递到网络；迟到的流被释放。
- 重复启动只保留一个操作；可恢复错误最多两次应用层尝试。
- 重新获取地址后渲染成功；失败后手动重试恢复。
- 登录、权限、删除、超限、损坏等错误不自动循环重试。
- 获取、渲染、重试等待阶段关闭；迟到结果不能改变 Closed。
- 渲染完成前不能进入 Ready；渲染超时会退出等待。
- 已打开后的播放错误清理资源并等待手动重试。
- 空文档不进入渲染器；中英文资源和重试命令状态。
- Graph 请求限定所选 drive/item；拒绝不匹配、文件夹、远程快捷方式和外盘响应。
- PDF 只探测前 1024 字节，检查 PDF 文件头；HTTP 错误页和链接失败正确分类。

## 实现边界

- 元数据和应用 HTTP 请求超时 30 秒，正文每次读取无数据超时 15 秒，控件首次渲染超时 60 秒。自动恢复最多一次，间隔 1 秒；Graph SDK 自身的请求行为不做全局修改。
- TXT/Markdown 最多 2 MiB，图片最多 20 MiB、4000 万像素；图片初次解码长边最多 2048，放大按需解码到长边最多 8192、4000 万像素。SVG 使用保持比例的有界栅格表面。超限提示下载，不截断正文冒充完整预览。
- Markdown 图片也受关闭取消控制：最多 16 张，逐张读取，每张最多 4 MiB，成功读取的累计字节最多 20 MiB。某张图片失败显示提示并保留正文；相对地址图片没有云端目录解析能力。
- PDF、媒体每次打开/重试都从 Graph 获取新地址。PDF 文件头探测后交给 WebView2；导航成功仅代表查看器打开，不保证整个 PDF 结构有效。密码和深层结构损坏仍由内嵌查看器反馈，不新增 PDF 解析引擎。
- 媒体沿用 MediaPlayerElement 和系统解码器；首次失败可有限恢复，播放中失败或持续缓冲超时后由用户重试，从头加载。
- 关闭会取消当前尝试，解绑事件，清除内容并释放自建播放器、媒体源和 WebView2；取消不作为网络错误。
- 下载先关闭并清理预览，再进入原有保存选择器和任务管理器。取消保存不报错。
- Markdown 超过 20 万字符、2000 行、单行 16000 字符或 4000 个竖线时，降级为完整纯文本。该边界用于控制旧解析器同步工作量，不是所有复杂语法的性能保证。
- 自动解码只识别 BOM 和严格 UTF-8；旧中文编码与无 BOM 的 UTF-16/32 由用户明确选择。合法 UTF-8 也可能与其他编码重合，用户仍可手动纠正。带 NUL 的内容提示编码错误。原生文本框规范化换行符，原始文件字节不会改写。
