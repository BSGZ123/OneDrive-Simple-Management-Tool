# 文件管理界面回归

第三批同盘移动/复制的独立内存界面入口、回归范围和验证记录见 [FileTransferUi](../FileTransferUi/README.md)。

此入口使用生产 `DrivePage`、列表/网格控件、菜单、弹窗和 ViewModel；Graph 请求全部由内存中的 `HttpMessageHandler` 返回。不会登录、读取令牌或访问真实云端文件。修改和删除只影响进程内的模拟数据，重启恢复初始状态。

在仓库根目录的 Visual Studio Developer PowerShell 中执行：

```powershell
msbuild "OneDrive Simple Management Tool.csproj" /restore /p:Configuration=Debug /p:Platform=x64 /p:CustomAfterMicrosoftCommonTargets="$PWD\Tests\FileManagementUi\Probe.targets" /p:OutputPath=bin\FileManagementUi\ /p:IntermediateOutputPath=obj\FileManagementUi\
& ".\bin\FileManagementUi\OneDrive Simple Management Tool.exe"
```

这是显式启用的独立构建入口，常规构建不会包含 `Probe.cs`。关闭测试应用后可重新构建。标题中的 `LOCAL` 和顶部说明用于区分正式应用。

顶部 `Reject mutations` 模拟修改操作的权限错误；`Reject refresh` 模拟列表加载错误。四项数据时请求延迟 600 毫秒，大目录时每次请求延迟 60 毫秒。保存选择器是真的系统对话框；本测试中下载仅验证打开和取消，完整下载仍需正式应用的可丢弃测试文件。转换返回模拟内容，不用于检验真实 PDF 格式。

## 2026-10-03 大目录与搜索正确性

### 行为与实现

- 目录和网盘搜索跟随 Graph 的 `@odata.nextLink` 顺序加载；首批成功后显示数据，后续页逐批追加。空的中间页不会提前结束，重复 ID 不会重复显示，重复分页链接和越出当前网盘的链接会报错。
- 后续页失败保留已有数据和继续位置，页面显示“尚未加载完整”；重试从失败页继续。停止加载不作为网络错误，新导航/搜索取消旧请求，旧响应不能覆盖当前结果或错误状态。
- “当前目录文件名筛选”针对全部已加载直接子项，后续页也继续应用筛选。忽略大小写，不递归；更换关键词和清除筛选都从原始目录数据重新计算。
- “当前网盘内搜索”先解析所选网盘的根目录 ID，再调用 item-scoped Graph search，包括子目录。关键词可能匹配名称、元数据和文件内容。不是跨账户/共享资源搜索，也不承诺提供云端搜索索引之外的匹配。
- 关键词去除首尾空白，空白/控制字符不能提交。单引号先按 OData 字符串规则转义，再由 Graph SDK 做 URI 编码；回归验证中文、内部空格、单引号、`&`、`#`、`%`、`+`、`?`。
- 外部网盘条目与 `remoteItem` 不作为当前网盘可操作结果；状态栏明确显示排除数量，避免把只有外部项目的目录显示为空目录。此轮未实现跨网盘共享快捷方式操作。
- 从网盘搜索结果进入文件夹时，根据实际父级构造面包屑，父链异常不提交导航；退出搜索回到发起搜索的目录。搜索结果页需先进入目标目录才能新建/拖入上传。
- 刷新按 ID 恢复选中项，包括出现在后续页的项。删除/重命名成功即同步原始缓存；刷新失败不会让旧名称或已删除项在清除筛选后重新出现。被新导航取代的修改后刷新不再向新页面写入旧错误；修改完成时也会沿用尚在等待首批结果的新搜索/导航。

## 2026-10-17 多选、排序和批量删除

列表和网格共用按文件 ID 维护的选择集合，支持 Ctrl/Shift 多选、Ctrl+A、全选已显示项和取消选择。切换布局、排序、刷新保留有效选择；新目录清空选择，筛选隐藏的项目取消选择。分页加载时全选只覆盖当前已显示项，刷新会继续恢复后续页的原选中项；加载期间不允许删除。

排序支持名称、数值大小、修改时间和升降序，可切换文件夹优先，默认名称升序、文件夹优先。规则保留在当前网盘 ViewModel 中，刷新、筛选及导航不重置，不跨应用重启保存。缺失大小或时间的项目排在对应分组末尾，同值按名称和 ID 稳定排列。

工具栏、Delete 键和右键菜单使用同一批量删除入口。右键已选项目保留整组选择，右键未选项目只选择该项；多选时重命名、分享等单项菜单禁用。弹窗快照目标，一次确认、默认移入回收站，也保留显式永久删除选项。逐项显示状态及错误，整批只刷新一次；重试仅处理失败项，已成功项目不因刷新失败而重复删除。结果保留到用户关闭，提交后不能更改删除方式。
