# 首页业务回归

```powershell
dotnet run --project Tests/HomeRegression/HomeRegression.csproj
```

直接编译生产 HomeViewModel、HomeDriveViewModel、HomeDriveService、账户令牌提供器和云盘配置存储。传输/同步 ViewModel 作为事件源替身；Graph HTTP 响应在内存中模拟，配置放在独立临时目录，使用测试保护器，不访问正式账户、令牌或云盘。

22 组检查覆盖：

- 首次使用的三个空状态；多云盘各自完成或失败，最多三个容量请求并发；损坏配置与空列表区分，恢复后可刷新。
- 导航取消、忽略迟到结果；慢初始化后的再次进入不重复请求；全部上传/下载状态的统计、变化、移除与清空；退出页面解除监听，再次进入重新统计。
- 同步活动、暂停、问题与配置异常；未知、零、负数、超配额和大数容量；超时提示及重试。
- 同名云盘保留各自账户与 drive ID；实际 Graph SDK 请求使用指定账户的静默令牌；缺失配额、错误 drive ID、401/403/404/429、登录失效和取消。
- 损坏配置不被覆写；中英文资源及页面 UID 完整性。
- 最近收藏只读本地数据、按收藏时间展示最多三项，保留账户身份；同步初始化缓慢或容量请求失败时仍可使用。
- 书签损坏与容量、任务状态独立，刷新后恢复；返回首页重新读取新增或移除的收藏；离开页面取消加载或定位，迟到结果不影响下一次进入。
